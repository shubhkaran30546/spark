# Spark – ASP.NET Core MVC Application

Spark is an ASP.NET Core MVC web application built with **.NET 7**, **Entity Framework Core**, and **Razor Views**.  
The project follows a layered architecture and supports database-driven features with authentication.

---

## 🚀 Tech Stack

- **.NET 7**
- **ASP.NET Core MVC**
- **Entity Framework Core**
- **SQLite / SQL Server**
- **Razor Views**
- **ASP.NET Core Identity**
- **BCrypt.Net**
